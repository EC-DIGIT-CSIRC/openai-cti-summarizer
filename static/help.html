CTI Extractor Help

Use this service to turn a CTI report from text, a URL, or a PDF into a structured summary that can be reviewed as rendered markdown or returned as JSON.

How To Use The Service

  1. Select the sensitivity level for the data you are submitting. Use PA only for public data.
  2. Select the model that matches the sensitivity and environment you are allowed to use.
  3. Choose one report input mode: upload a PDF, fetch a report URL, or paste report text directly.
  4. Read and accept the handling and review checkboxes below the input area.
  5. Submit the report and wait for the generated CTI summary.
  6. Review the output before using it in any operational or reporting workflow.

Input Modes

  • File upload: Upload a PDF CTI report. The service extracts the text and sends it for summarization.
  • Fetch from URL: Provide a direct URL to an HTML, text, or PDF report that the service can access.
  • Copy and paste: Paste report text directly when the source is not available as a file or URL.

Output

The service asks the configured LLM provider to return a structured CTI summary using the application schema. When JSON output is enabled in the service configuration, the API response is the JSON object from the summarization flow. Otherwise, the result is rendered as markdown on the page.

Typical sections include the executive summary, key points, TTPs, indicators, threat actors, confidence, report metadata, and any generated YARA rules.

Limitations

A human must check the generated output before it is trusted or shared.

  • OpenAI or the configured LLM provider may process submitted data through its API. Select PA only for public data. Do not select PA for CU or SNC data.
  • The model may miss important details or context that a human analyst would recognize as relevant.
  • The model may generate summaries that are factually incorrect or misleading.
  • The model may struggle with complex, technical, ambiguous, or poorly extracted report text.
  • The model may generate summaries that are too brief, too long, or unevenly detailed.
  • The model may occasionally produce unsafe instructions or biased content.
  • The model may have limited knowledge of events, actors, tools, or vulnerabilities after its training cutoff unless those details are present in the submitted report.
